Minecraft World Generator

国土地理院のDEMデータとOpenStreetMapから、現実世界の地形を再現したMinecraftワールドを自動生成

Java 24 Maven React + Leaflet Minecraft 1.21.8

概要

このツールは、国土地理院が提供する数値標高モデル（DEM）とOpenStreetMapの地図タイルを使用して、 日本国内の任意の場所をMinecraftのワールドとして生成します。 標高データをブロックの高さに変換し、現実の地形を忠実に再現します。

主な機能

地理院DEM対応

国土地理院の標高タイル（dem_png）を取得し、RGB値から標高をデコード。海面（0m）から富士山（3776m）まで正確に再現。

OSMタイル表示

OpenStreetMapのタイルを背景地図として表示。WebUIではLeafletを使用し、直感的な範囲選択が可能。

Minecraft 1.21.8 対応

最新バージョンのワールドフォルダ形式で出力。regionファイル（.mca）とlevel.datを自動生成。

Web UI / CLI 両対応

ブラウザで地図上から範囲を選んで生成、またはコマンドラインから座標指定で一括生成が可能。

ZIPダウンロード

生成完了後、ワールドフォルダをZIP圧縮してワンクリックでダウンロード。サーバーへの導入が簡単。

並列ダウンロード

最大64スレッドでタイルを並列取得。広範囲でも高速に処理完了。進捗はリアルタイムで表示。

使い方

1

ビルド

MavenでJARをビルドし、Web UI用のフロントエンドもビルドします。

2

Web UI を起動

java -jar untitled10.jar --webui でWebサーバーが起動し、ブラウザが自動で開きます（デフォルト: http://localhost:8787）。

3

範囲を選択

地図上でクリックして1点目・2点目を指定。ズームレベル（3〜15）で詳細度を調整。2点で矩形範囲が確定します。

4

生成実行

「ワールドを生成」ボタンで開始。進捗バーと残り時間（ETA）がリアルタイム表示されます。

5

ダウンロード

完了後「ワールドをダウンロード (ZIP)」で保存。解凍して server.properties の level-name にフォルダ名を指定すれば即プレイ可能。

CLI モード（コマンドライン）

Web UIを使わず、コマンドラインから直接生成することも可能です。

# PNG画像として出力（標高カラーマップ） java -jar untitled10.jar # 対話的に座標・ズーム・出力先を指定 # Minecraftワールドとして出力 java -jar untitled10.jar # モード選択で "2" を入力 # 対話的にタイル座標・ズーム・出力先を指定

API エンドポイント（Web UI用）

POST /api/generate - ワールド生成開始
GET /api/progress - SSE で進捗取得
GET /api/download - ZIPダウンロード
GET /api/tiles/{z}/{x}/{y}.png - OSMタイルプロキシ
